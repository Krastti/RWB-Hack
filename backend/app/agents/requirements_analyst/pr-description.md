## Что изменилось

Добавлен Requirements Analyst Agent: бизнес-текст преобразуется в проверяемые
FR/NFR, роли, сценарии, критерии приёмки, ограничения, риски, допущения и вопросы.
Нерешённые critical-вопросы дают `waiting_for_input`; ответы возобновляют анализ
с сохранением FR ID. Результаты включают JSON, Markdown handoff, checksum и usage.
Есть CLI для реальной модели и отдельной локальной проверки данных.
