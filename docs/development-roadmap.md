# Роадмап разработки продукта

Основание: [спецификация](project-specification.md). Здесь только разработка frontend, backend и агентов. Задач по тестированию, сборке, деплою, Docker, CI/CD и сканерам безопасности нет.

## Как брать задачи

Одна строка таблицы — отдельная задача с одним результатом и владельцем. FE — frontend платформы, BE — backend платформы, AG — агенты. Разработчик берет задачу целиком; задачи одной цели можно распределять между людьми.

В колонке «Вход» указана настоящая зависимость. Если необходимый runtime еще не написан, использовать пример ответа из `contracts/examples/` или реализацию интерфейса в памяти. Это рабочие адаптеры для параллельной разработки платформы; они не заменяют предметную логику генерируемого проекта. После появления настоящего компонента задача подключения перечислена отдельно.

Порядок волн не означает, что вся команда ждет завершения предыдущей волны: достаточно указанного входного контракта. Сроки не назначены, поскольку состав команды и длительность работ не заданы.
